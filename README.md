## Reporting a Bug
Please check the **Issues** tab first to see if the problem has already been reported. When creating a new report, include:

1. **Minecraft Version:** (e.g. `1.21.1`, `1.21.11`, `26.3`)
2. **Platform / Loader:** `Datapack`, `Fabric`, `Forge` or `NeoForge` (plus loader version)
3. **SH: Buried Halls Version:** (e.g. `1.6.1` – shown in the file name or the mod list)
4. **Environment:** Singleplayer or server (plus server software, e.g. Fabric, NeoForge, Paper)
5. **Modpack:** Name and version, if you are playing one
6. **New or existing world:** Structures only generate in newly generated chunks. Did you add or update SH: Buried Halls in an existing world?
7. **Log / Crash Report:** Upload your `latest.log` or crash report to [mclo.gs](https://mclo.gs/) and paste the link (please don't paste the full log into the issue)
8. **World Seed & Coordinates (for generation bugs):** Use `/seed` and the `F3` coordinates of the broken room, corridor or entrance
9. **Other Mods / Datapacks:** Especially other world-generation or structure mods
10. **Screenshots:** They help a lot with generation bugs

## Suggestions
Ideas for new rooms, entrances or features are welcome. Open an issue and start the title with `[Suggestion]`.

## Modpack Creators
You're welcome to include SH: Buried Halls in modpacks, as long as you credit **skyhunter77** and link the official Modrinth page. Standalone reuploads, mirrors and modified public versions are not allowed without permission.

For compatibility problems or questions, open an issue and start the title with `[Compat]`.
